# Levitage Cafe — Homepage

A responsive, Persian-first landing page for Levitage Cafe in Janah, Hormozgan.

## Run it
1. Extract `levitage-cafe-website.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or another browser.
3. Internet is only needed for the optional Google Fonts and Google Maps link. The page and local photos work offline.

## Files
- `index.html` — page structure and Persian content
- `style.css` — layout, colors, responsive/mobile styles
- `script.js` — mobile menu, copy-phone button, footer year
- `assets/` — the original photos supplied in the conversation
